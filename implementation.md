# Implementation and review evidence

The recorder now activates the existing predecessor journal for every recorded search. Each application remains owned once by the immutable proof; clashes retain native binding frames and cursors. Prepared bound laws remain distinct source evidence. Consistent proofs without clash evidence discard unused journal storage and retain their v3 serialization. Unrecorded decisions do not activate the journal.

Replay borrows the selected applications in order, validates descending predecessors and source/contract binding, checks actual graph premises and licensed deterministic/branch heads, applies the native graph operations, then compares actual final binding identities and observed body facts. It never invokes solve/saturate/search. A direct clash replay additionally regenerates every cited branch's source alternatives; a whole refutation checks that its selected choices exactly match the enclosing branch path. Checked source identity is exposed separately from the structural node and is never a local contradiction authorization.

The v5 grammar stores one application arena before the clash list, validates strictly earlier predecessors and existing cursors, and retains the original recording ceiling. v4 decoding reads its source laws and embedded prefixes through the same application codec and normalizes them into the shared arena. That migration is bounded by the aggregate recording ceiling; re-encoding is v5, so historical v4 byte digests intentionally migrate. Unsupported v3 premises remain explicitly unattested. The old schema-local support_steps accessor was removed with its obsolete support owner; current_support_applications reports stored application count on the proof, and current_support identifies the per-clash evidence. No downstream GMEOW crate calls the removed accessor.
