## Chosen architecture

1. **One real query workspace owner.** Extend the static DatasetView contract with an explicit owned reservation capability for retained operational execution. Segmented reservations already own their Arc budget; resident execution keeps its erased no-op fast path. Forward the capability through every adapter/reference implementation and update custom native fixtures. Do not fabricate an owned guard from a borrowed RPIT return. The shared query admission owner holds its actual reservation, current admitted capacity and first typed resize refusal. A custom adapter may return a refusal without latching view status: preserve that typed cause and inspect it at publication. A pre-existing sticky view failure outranks the admission cause, which outranks derived evaluation errors/trips.

2. **Certified bounds where possible, growth admission where needed.** Replace the query-shape/input allowlist with a checked algebra admission walk. Known row/schema/planner/path/order/distinct/grouping/intermediate/output capacities receive checked bounds covering simultaneous owners and actual vector/hash capacity growth. Selective BGP probes remain selective; do not price every selective query as the whole dictionary. Cardinality used as a byte proof must cover the actual physical and virtual RDF stream, active default/named graph semantics and empty graph enumeration; add an explicit full-stream certificate if the existing quads-only cost hint is insufficient. Avoid double-counting segmented estimates that already include all tables. Overflow refuses before allocation rather than saturating a cost heuristic.

   Thread the live owner into EvalCtx and nested contexts, replacing marker-only admission. Stored-term size certificates apply only to stored values. At allocation owners, reserve before potentially unbounded computed string/arithmetic/aggregate/minted-value growth, substitution copies, term scratch and output staging. Owners either have a certified complete bound or use local checked pre-growth admission; after-the-fact scratch interning is insufficient. Use fallible capacity allocation and map its real failure to an actionable allocation diagnostic. Track coexisting pins, original allocations and replacement capacities; release only after the covered allocation is gone. Shared internal work gets one home, not parallel pricing implementations.

3. **Native producers price their actual work.** Extend the existing property-function/native extension admission seam with a workspace certificate or admitted pre-growth capability. Admitted native text search and occurrence relations cover needle analysis, full ranking when post-rank filters require it, ranking/intermediate/cursor buffers, bound-value copies, term rendering and emitted values. Pre-existing caller-owned index storage remains caller-owned. Row ceilings are neither byte certificates nor permission to truncate before a post-ranking filter. Preserve witnesses, ranking, modes and filtering. An opaque custom producer without the required certificate remains a truthful unadmitted producer; this must not be used to refuse supported built-in/native text paths. Apply the same law to configured functions/aggregates and nested calls that are admitted. Focus graph is the caller-supplied graph, never a synthesized resident copy of operational storage.

4. **Retained publication shares allocation and admission.** Introduce a retained operational payload distinct from the raw resident SparqlResult. It owns immutable shared payload plus the reservation covering that payload. Complete results, governed partial answers and operational EXPLAIN share their engine-owned allocation and lease on ordinary Clone. Ownership-carrying extraction keeps that lease. Do not expose a field move or engine-provided raw extraction that drops it. Keep borrowed immutable access for serializers and normal consumption; a caller explicitly copying borrowed values owns that new independent allocation. Do not attempt to police arbitrary client allocation. Update every real production consumer of changed APIs, including shared facade/host plumbing if compilation exposes it. Scoped visitor outputs owned by the visitor remain caller-owned; evaluator scratch remains admitted throughout the visitor and is released only after it is destroyed.

5. **One actual execution path and final checkpoint.** Wire direct, prepared, shared-operation governed, stop-signal and measured EXPLAIN entries to the same admission and retained-publication law. Remove obsolete bounded refusals only after their owners are priced. Keep configured standpoint/loss vocabulary behavior active on bounded storage, pricing actual copied configuration. Maintain cancellation, governor evidence, destination graph atomicity, bag/correlation semantics, and final source checkpoint precedence. No complete result/explanation or uncertified partial rows escape a failed source/checkpoint. Genuine governor partial answers retain their output admission.

Known costs: the owned capability and retained operational API require a coherent migration of native adapters/consumers. This is accepted GREENFIELD work; do not add a speculative compatibility engine. Declined: global allocator interception (not a sound library contract), whole-store admission for selective queries (defeats persisted selective storage), static stored-term multipliers for computed values (not a bound), and new optional features/dependencies (forbidden and unnecessary).

Segmented growth admission must use the same inclusive storage/cache/pin budget as initial admission, evicting eligible unpinned cache blocks where necessary. Avoid a strong-reference cycle between a retained owner and cached blocks. Bounded external adapters must supply an actual owned capability; a resident default may not silently become a no-op capability for a bounded adapter.
