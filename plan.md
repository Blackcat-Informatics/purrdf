## Design decisions and executable completeness contract

1. Connectivity means sharing a bound VARIABLE in any of four positions. Shared
   constants never connect components. Preserve deterministic selectivity ties,
   cycle certification, coordinates and authored premise restoration. Task1
   proves bridge-before-type, predicate/graph connections and hybrid ordering.
2. Certify factors using positive variables plus negative outer-variable coupling.
   Evaluate independent components once per frozen round. Separate Old/New/Full
   matches and use deterministic first-new-component decomposition: preceding
   components Old, anchor New, following Full. No entirely old firing. Scheduled
   model-reading rules retain full-current-model evaluation. Task2 proves exact
   facts, delta eligibility, empty factors and additive independent-head work.
3. Project each conjunctive head separately, using all four positions. Constant
   or one-factor heads reduce existential components; multi-factor heads stream
   only their necessary product. No buffered positive product. Task2 proves
   additive counts/state and exact required two-factor output against exhaustive
   small oracles, including negation coupling and insertion permutations.
4. Witness law is saturated proof height, saturated summed source heights, sorted
   facts, authored rule, authored source facts. Local winners are insufficient.
   Per projected binding retain height-threshold frontiers for BOTH best(sum,lex)
   and pure lex. Minimize saturated global proof height first; when it equals
   u32MAX raw threshold is u32MAX, otherwise height-1. Sum component minimum sums
   saturating: if saturated choose pure lex, otherwise sum-first. Restore authored
   positions and use one comparator/arithmetic home. Task2 tests height masking,
   sum saturation, boundary values and exhaustive witness equality. Task3 repairs
   insertion-first assumed confirmations with this same law.
5. Opaque guards are multiplicity/order barriers: Bindings does not certify
   replayability, FreshBlank/Assign can consume mint state. Preserve stage-major
   guard execution, caller-thread context, fresh outputs, computed surfaces and
   reached operational failures. Empty factors preclude callbacks. Single-atom
   negation's unbound-position behavior and conjunction-local bindings remain
   distinct. Task3 tests public SRL/SHACL callers, fresh blanks/BNODE, multirow
   producers, triple terms, computed negation, malformed rows and crossed errors.
6. Admit before evaluator-owned binding/source/computed candidate expansion,
   including touched guard/negative/factor/head loops. Round-wide remaining plus
   ONE refusal sentinel replaces multiplied per-rule allowances. Guard-free
   parallel work shares credits and reduces in authored order; guarded callbacks
   stay on caller thread. Exhaustion is total typed refusal, never no-match or
   partially committed closure. Task4 tests0/exact/one-below, asymmetric many-rule,
   large guard and negative traversal at1/4/32 workers, including refusal counters.
   Callback Vec and SHACL Producer eager triples are explicitly NOT bounded by
   these consumer checks; later portfolio memory-interface work remains required.
7. Bump planner AND calculus versions deliberately because budget observations
   and assumed-confirmation preference change. Keep canonical authored rule hash
   stable. Task1/3 tests frozen identities and authored proof content. Do not claim
   the physical-change exemption when reports change.
8. Task5 runs actual release `purrdf rules --srl RULESET --explain=PROOF INPUT OUTPUT`
