## Chosen design

CandidateDepths carries caller-selected per-stratum work bounds, independent of k or selectivity. CandidatePlan has a distinct canonical identity and passes through the existing admission/compiler waist. A sealed CompiledRead family routes both compiled bundles through the same execute/execute_within bodies. The separate union consumer preserves original ranks, every producer's evidence and failures, and exact prefix completion; it computes no score or relevance order. Original fusion/search identities and version-4 plan bytes remain intact. Shared receipt/rank checks retain one implementation.

DatasetView::cost receives the actual pattern and opaque ProbePlan. AccessCost records caller-measured work, examined rows, optional pages and residency; the default derives work from the original cardinality estimate. The existing native DP and greedy optimizer carry separate work and row estimates, use work for ordering and cardinality for selectivity/replay. Default math/ties stay identical. Existing statistics fingerprints continue to identify cached orders. No alternate optimizer or fixed hardware cost model is introduced.
