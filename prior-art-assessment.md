Read `prior-art.md` and its coverage limits, the complete three-issue intake,
root `.baseline`/`.goals`, approved sibling `PURRDF-SEAM.md` sections 3–4, and the
actual current `rdf-core/src/loss.rs`, `sparql-eval/src/solution.rs`,

forge repetition, external submission, or runtime claim.

The native solution is currently cells only: `Solution` is the inline small
vector and `SolutionSeq` has a shared schema plus bag rows. It is the real carrier
to widen once, including delivered rows, rather than wrapping only final public
results. Datalog's relation arrangements and proof derivations need the same
query-local semantic ids while retaining their existing join/duplicate law.

`LossEntry`/`LossLedger` already own stable conversion cause codes, locations,
sorted deterministic JSON and the conversion contract. Reuse those causes and
keep that contract intact. They do not already implement per-row knowledge,
frames, queryable RDF reifiers, or reason acceptance; treating them as complete
prior art would miss the requested production work. View operation status and
property-function service declarations similarly establish runtime and provider
facts, not every output row's semantic evidence.

Retrieval already holds lexical predicate restrictions in `RequestTerm`, and
`StratumUnit` owns checked depth, declaration and actual compiled query.
`depth_argument` sends the producer depth/probe value; the outer emitted LIMIT
also bounds the read. Consequently a predicate FILTER attached after that
producer call cannot recover lost candidates. The scoped request must reach the
actual producer before either truncation. Existing producer contracts,
attribution, candidate/fusion stream order and terminal receipts are reusable;
their errors cannot be relabelled semantic undecided rows.

Owned GMEOW FOUR/standpoint material is useful algebra and identity precedent.
Reuse must distinguish truth meet for conjunction from information join for
duplicate alternatives, adapt frame/completeness independently, and omit donor
serde dependencies, namespaces and size caps. Licensing for owned code is
settled by the user; no extra gate is introduced. Hash framing, canonical
identities, native numeric work and shared storage stay at their existing homes.
