## Open finding HF1 — MEDIUM: cold checked reinterning skips native composite blank registration

Location: `crates/rdf-core/src/ir/global.rs:519-545`, especially the literal arm at lines 538-545. The existing public native invariant is documented and implemented by `GlobalDictionary::intern_literal` at lines 566-583: composite literals register their concrete embedded blank identities, preserving `(label, scope)`, before registering the literal. Ordinary `GlobalDictionary::intern` invokes that home at lines 632-640. The pre-change `reintern_validated` also invoked `intern_literal` in its literal arm.

The new `try_reintern_validated` invokes `try_intern_lookup(GlobalTermLookup::Literal { ... })` directly. It never invokes `cdt_embedded_blanks`, nor any registration home that does so. `reintern_validated` now delegates to that path. For a fresh dictionary and a validated `TermValue::typed_literal("[_:bnode1]", purrdf_cdt::CDT_LIST)`, ordinary `intern` registers datatype, embedded default-scope blank, and literal; checked/cold validated reinterning registers datatype and literal only. `term_id_by_value(&TermValue::blank("bnode1"))` therefore differs. The same omission applies inside recursive triple terms and to qualified scoped blank identities in nested CDT values. Lexical bytes remain present; the absent embedded identity is the defect.

The existing `intern_value_registers_composite_blanks_inside_triple_terms` test does not cover this: its `reintern_validated` assertion at line 1181 occurs after `intern` has already populated the very same dictionary and embedded blanks. A hit cannot witness cold registration behavior. The global test receipt showing 23 passing tests therefore does not clear this discrepancy.

Current complete-page/snapshot dictionary loops also iterate the source's embedded-blank entries separately, so they can mask the missing operation in this shared method. This review does **not** claim an established wrong public stack query result from that case. It establishes a source-level semantic regression in the shared reinterning home introduced while making it fallible; validated input authorizes bypassing IRI reparsing, not bypassing RDF identity registration. The blast radius includes ordinary `PageTranslation::try_build`, existing `PagedDataset::compact`, and new snapshot/tombstone dictionary composition, all of which now depend on this changed shared home.

Required disposition: preserve checked allocation/address refusal while routing composite-literal blank extraction/registration through one native implementation home shared with `intern_literal`. Do not introduce a second composite parser or silently narrow the validated method's semantics. Add a focused cold-dictionary comparison between ordinary `intern` and checked validated reinterning for direct and nested CDT values: default/scoped blank lookup, exact lexical bytes, opaque quoted text not registering a blank, idempotence, and recursive triple containment. Retain the existing global and affected paging checks. A concrete source fix or evidence proving the native invariant is intentionally different is needed; no such authorization appears in the issue or plan.
