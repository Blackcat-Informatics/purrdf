# Native contextual certainty owner proposal

`certainty-owner-draft.patch` is a standard four-home patch against the current shipping postimage. Its ordinary hunks do not touch `invocation_mode` or `term_is_bound`. `patch --batch --dry-run -p1` passes. No source was edited and no compiler, build, or test was run. The Stage assembler is historical evidence after integration, not a command to rerun over the applied postimage.

The production seam is `property_fn_plan::collect_certainly_bound_admitted(pattern, &workspace) -> Result<VarSchema, EvalError>`. The contextual companion is `collect_certainly_bound_in_admitted(pattern, &context, &workspace)`. `collect_bound_admitted(pattern, &context, written: Option<&VarSchema>, &workspace)` exposes the original complete contextual/promised-binding law for bounded planner callers. These return only variables the pattern itself certainly binds; the given context is not automatically added to the result.

The original postorder body is migrated in place. Its Enter/Exit/LateralLeft/ApplyLeft steps preserve every actual GraphPattern variant and the original input ordering. Arena, value stack, step stack, nested-triple worklist, expression boolean stacks, and requirement stacks use the existing `AdmittedVec` allocation home. Every set is the existing immutable `VarSchema`; its column buffer, wide hash index, and shared header come from `SchemaBuilder` or `from_vars_admitted` before allocation. Published schema clones are shallow and retain their original grants. No syntactic schema substitutes for certainty, no arbitrary subset is admitted, and no row or term multiplier prices bytes.

LATERAL computes the left result first and widens the right context. APPLY removes each declared input from both inherited context and promised writes before supplying its renamed driver only when the driver is certain, contextual, or promised. An admitted shadow-input schema supplies indexed membership for wide policies; mutable schema builders append supplied inputs amortized. Optional APPLY contributes only its left result, as before. Project narrows contextual bindings to projected variables while promised writes retain the original substitution reach. FILTER removes promised variables from row constraints. Join unions, Union intersects, LeftJoin/Minus retain only their left result, and Group retains the original aggregate/explicit-group certainty rules. All original expression cases and Truth/Falsity/Value requirement combinations remain in the same bodies.

Literal Truth/Falsity requirements now call `expr::constant_ebv_admitted`: it borrows authored lexical/datatype spelling, invokes the existing complete `ParsedValue` native dispatcher, and applies the same XSD `effective_boolean_value`. A physical refusal propagates as EvalError; it cannot turn into a malformed literal or an impossible requirement. The old resident EBV test seam delegates to it. No numeric arithmetic, promotion, or rendering body is changed.

The original resident planner APIs remain for caller-owned DetHashSet inputs/output, converting them only at their resident boundary into the same native certainty body. The old raw set combiners survive solely inside the existing recursive test oracle. Bounded forecast/PositivePlan/BGP callers must use the admitted schema seam directly; numeric owns that caller migration. The remaining resident feasibility rewrite is a separate source owner's prepare/admission migration, not a claim that a caller-owned set grants newly created bounded storage.

The existing `VarSchema::union_admitted` home now performs one schema-builder fold over both borrowed column lists. Empty-left and already-covered-right fast paths clone an existing published schema without allocation. This preserves first-seen order and duplicate elimination while removing repeated immutable-prefix copying. Group and flat conjunction requirements also build their result once rather than reallocate the prefix for every supplied variable.

The pre-existing 200 generated pattern/reference comparisons, contextual input-shadowing and retry cases, 300 generated expression/reference comparisons, strict-function drift fixtures, and deep nested-triple fixtures now exercise the native admitted body through their resident wrappers. Three additional fixtures reuse the actual workspace reservation law: a 128-column returned schema outlives its workspace and shallow clone; several first/mid-construction refusals destroy all scratch owners and move the original typed cause without cloning; LATERAL plus BIND and FILTER use the same admitted context and requirement homes and release scratch. These fixtures are uncompiled and unrun. They establish no current qualification result; the sole writer's shared lane must compile and run them with the grouped affected checks.
