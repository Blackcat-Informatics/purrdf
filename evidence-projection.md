# Landing evidence projection

The three review files named in evidence-projection.json are substantive
projections of the original API evidence. Only automatic provider HTML
attribution comments were omitted to satisfy the mandatory Git attribution
guard. Review findings, suggestions, limitations, IDs, URLs, timestamps and
revision fingerprints remain. Existing fingerprints identify original API
bodies, rather than these projected bodies. JSON whitespace was normalized.
The projection receipt records both byte identities and omission counts.

Untouched originals remain in the original selected Stage directory and in
the canonical queue's completed-local/1181/stage-original-20261108 directory.
The required synchronization journal and every other captured evidence file
retain their original bytes. Raw execution logs remain local under the normal
archive policy. This archive does not claim to reproduce raw review bodies.
