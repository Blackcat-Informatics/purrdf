review-current.json retains the complete technical comment body, original stable
comment/node IDs, author, source URL, update time, reviewed base/head and coverage
of comments, review submissions, inline comments and threads. pr-comments.md is
the same technical body in readable form. The original technical findings,
architecture assessment, risk, check tables and docstring advisory are preserved.
Only navigation containing a private UI token, decorative pictures/HTML wrappers,
automatic summary banners, billing text, poems, help/automation checkboxes and
suggested finishing actions are omitted. Picture/check-image alternatives retain
their status words. No GitHub comment is edited. Empty review/inline/thread
collections are recorded with completed pagination, rather than inferred.
pr-checks.txt is the owner's historical pending snapshot; checks-current.json is
the refreshed final check evidence. No source qualification is inferred from the
old pending snapshot.
