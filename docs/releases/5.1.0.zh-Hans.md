# PurRDF 5.1.0 发布说明

## 源码归档

GitHub 发布页附带 `purrdf-source-5.1.0.tar.gz`，其中包含 `rust-v5.1.0`
标签所指提交的完整源码树。归档内包含项目许可证文本、第三方声明及其来源记录。
该归档不是已编译的 C SDK，也不同于 GitHub 自动生成的源码下载项。

`SHA256SUMS` 同时列出源码归档及其许可证凭据
`purrdf-source-5.1.0.license-receipt.json`。两者都有构建来源证明。
下载发布附件后，可按[发布资产验证说明](../RELEASE.md#verification)校验文件，
并确认构建来源证明绑定到相同的发布标签和提交。
