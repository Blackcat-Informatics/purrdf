# PurRDF 5.0.1

PurRDF 5.0.1 is a security release. Upgrade every PurRDF package from 5.0.0
together.

- Python SHACL validation now authenticates exact PurRDF native store classes
  before accessing their state and freezes an owned dataset snapshot. Forged or
  stale capsules are rejected without dereferencing caller-supplied memory. See
  [GHSA-3rr5-8657-xhvx](https://github.com/Blackcat-Informatics/purrdf/security/advisories/GHSA-3rr5-8657-xhvx).
- GTS readers now offer one cumulative resource contract across Rust, Python, C
  and the command line, including compressed transports, nested segments and
  deferred blobs. Existing entry points preserve trusted-input compatibility
  and remain unbounded. For untrusted artifacts, call the Rust
  `*_with_limits` entry points, pass Python `GtsReadLimits()`, call C
  `purrdf_from_gts_with_limits`, or use the CLI's `--gts-safe-read`.
  Tune individual finite ceilings to the admitted workload; large datasets do
  not require disabling admission control. See
  [GHSA-876v-7mcq-9jfw](https://github.com/Blackcat-Informatics/purrdf/security/advisories/GHSA-876v-7mcq-9jfw).

The 5.0.1 WatDiv release measurement used the pinned 10M dataset
(10,916,457 triples; 1,542,624,409 extracted bytes), executed all 20 seed-0
queries with the 5.0.1 binary, and reproduced the recorded 434,748 total answer
rows.
