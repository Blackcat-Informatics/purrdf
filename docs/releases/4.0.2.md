# PurRDF 4.0.2

PurRDF 4.0.2 improves native dataset freezing and corrects finite nested-term
handling, GTS dictionary access and source-encoding behavior while preserving
existing v4 contracts.

- Ordinary native freeze prepares query statistics and source proofs on demand.
  Existing proof access remains available; first use prepares the required
  metadata. Publication with an explicit memory account retains its admitted
  metadata before returning the dataset.
- Native RDF storage, ingestion, event transfer and GTS resolution use
  iterative term traversal. Finite deep terms retain their identities, while
  cycles, missing operands and resource refusals retain native diagnostics.
- GTS import and export support admitted caller-owned dictionaries and explicit
  spilling. Indexed lookup verifies locators and selected blocks against the
  bound source, capabilities and policy. Indirect references use a separate
  preparation step with retained numeric projections under the same metadata
  ceiling. Selected RDF import returns its own native owner; global verification
  remains an explicit full-reader operation.
- Prepared SELECT cursors expose schema and borrowed rows with original terms
  and evidence. Settlement reports completion, consumer stopping and original
  source or governor failures. Buffering reports identify retained operator
  units, and cursor destruction releases suspended reservations.
- Strict GB 18030 conversion selects an explicit 2005 or 2022 Amendment 1
  profile. Encoded RDF ingestion retains original source-byte contributions and
  admitted conversion storage. Mismatched content BOMs are refused.
- CSVW projection and ground SPARQL result comparison preserve native term
  identity and original failures. OWL Direct literal keys and source-bound
  positive proofs preserve their semantic evidence. Lossless tar inventory
  retains original framing and historical acceptance with bounded PAX lookup.

Existing v4 public contracts and valid artifact readers remain supported;
the C ABI remains 0.20.0. See the
[complete changelog](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.2/CHANGELOG.md)
and [v4 migration guide](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.2/docs/MIGRATION-4.0.md).
