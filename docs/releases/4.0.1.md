# PurRDF 4.0.1

PurRDF 4.0.1 refreshes W3C conformance reports, publishes its shared development
libraries and improves bounded RDF storage and SPARQL execution.

- SHACL 1.2 uses the November 6 W3C suite and vocabulary snapshot, with an
  explicit `ShaclProfile::ED_20261106` law. Native and CLI expression evaluation
  retain typed failures and correct focus-node handling. Earlier dated laws
  remain available; release EARLs identify the tagged source.

- `purrdf-testkit` provides golden files, deterministic property testing,
  temporary paths, exact numeric oracles, frozen vectors and benchmark and
  test harnesses. Its bundled JSON Schema meta-schemas carry their original
  BSD notices, and workspace helpers resolve paths from the downstream caller.
- `purrdf-alloc-probe` provides a counting allocator with explicit per-thread
  and whole-process measurement windows.
- `purrdf-conformance-kit` provides parsed-input manifest reading, exact
  result-bag and SHACL report grading, reviewed inventory admission and EARL
  report construction.
- Segmented dictionary limits charge actual stored terms and text, preserving
  duplicate insertion and refusal behavior.
- Finite SPARQL `ORDER BY` windows use exact bounded selection with stable
  ordering. Fifteen native query and SERVICE corpus cases cover result bags,
  unbound values, paths and blank-node scopes.
- Columnar projection, decoding and rejected-datatype diagnostics retain shared
  term graphs without recursively expanding their children.

Existing v4 public contracts and valid artifact readers remain supported;
the C ABI remains 0.20.0. See the
[complete changelog](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.1/CHANGELOG.md)
and [v4 migration guide](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.1/docs/MIGRATION-4.0.md).
