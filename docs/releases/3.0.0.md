# PurRDF 3.0.0

PurRDF 3.0.0 updates the shared RDF 1.2 engine and its Rust, Python, JavaScript/WASM and C bindings.

- Native JSON, YAML, CBOR, XML, hashing, Unicode and Ed25519 implementations reduce the external dependency surface.
- HNSW indexing, vector-distance kernels and deterministic RDF embeddings support the shared retrieval engine.
- Typed read failures, pinned term guards and an opt-in certified segmented store support bounded selective queries and streamed RDF export.
- Python SQL/Parquet exports use the native canonical five-table representation, including blobs and empty named graphs.
- First-party code adds MulanPSL-2.0 alongside MIT and Apache-2.0. Distributions retain component grants and full recipient notices.

This major release changes `DatasetView` read/error contracts, logical 64-bit addresses, diagnostic construction and Python export schemas. JavaScript dataset IDs, generations and asynchronous exchange IDs now use `bigint`. See the [migration guide](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v3.0.0/docs/MIGRATION-3.0.md) before upgrading and the [complete changelog](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v3.0.0/CHANGELOG.md) for the full change history.
