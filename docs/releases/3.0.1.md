# PurRDF 3.0.1

PurRDF 3.0.1 repairs SHACL validation and SPARQL planning, and completes the
coordinated Rust, Python, JavaScript/WASM and C release.

- SHACL-SPARQL now applies pre-bound focus nodes inside nested `OPTIONAL` and
  other graph patterns. Missing-property constraints correctly report nodes
  that lack the property, including blank and quoted focus nodes.
- `ShaclDatasetView::named_graph(source, graph)` validates one native named graph
  as the default graph without copying its quads or building another index.
  Core validation, class membership and SHACL-SPARQL share the selected graph.
- Fixed-length alternative property paths and connected joins around `UNION`
  use native indexes and carry bindings through their join schedule, preserving
  duplicate solutions and blank-label scope under the existing query limits.
- Rust publishing waits for dependent versions in Cargo's registry index, and
  the GitHub Release verifies its C SDK and checksum assets before publication.

Users validating missing properties with SHACL-SPARQL should upgrade and rerun
validation. The [3.0 migration guide](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v3.0.1/docs/MIGRATION-3.0.md)
still applies. See the [complete changelog](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v3.0.1/CHANGELOG.md)
for details.

Thanks to [@dshchyhlinski](https://github.com/dshchyhlinski) for the excellent
