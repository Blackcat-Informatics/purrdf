# PurRDF 4.0.0

PurRDF 4.0.0 updates the shared RDF 1.2 engine and its Rust, Python, JavaScript/WASM and C bindings.

- Exact XSD numerics throughout: integers and decimals of every size share one exact value API, and decimal division keeps every digit of a terminating quotient.
- Datalog gains shared head conjunctions, native inequality and guard values, native integer dictionaries, incremental maintenance across signed transactions and explicit, removable capacity limits.
- SHACL adds the editor's-draft law and typed rule sets, and SRL inference accepts a stop signal. Direct OWL subsumptions and types require a fully decided certificate.
- New `purrdf-glob` and `purrdf-toml` crates add compiled Unicode glob matching and a lossless TOML 1.1 codec; Function Ontology catalogs read and write through one admission path.
- Exact BM25F ranking drops its admission ceilings, and segmented storage moves to data profile 7.
- Named graphs emptied by Update are remembered by default across every surface.
- Queries, UPDATE and rules retain actual execution receipts; host results carry receipts beside payloads, with explicit unavailable identities for uncertified external implementations.
- Canonicalization and canonical identities return typed refusals instead of panicking, and the shared structured inspection protocol exposes native fields and retained causes without consumer-side enum mirrors.
- Structured reasoning retains native scoped answers and source-bound checked proofs; growing construction and term-inspection contracts can extend without replacing the current ground behavior.
- Native RDF ingress, SHACL admission and rule helpers, reasoning requests and GTS composition expose typed causes through the shared inspection protocol and host boundaries. Checkout-based conformance helpers leave the published SHACL API.
- MIME documents expose immutable verified state, ShEx reports operational exhaustion as a typed refusal, and JSON Schema callers can select a truthful reference-chain policy.

This major release changes Rust APIs, persisted segmented stores, Datalog proof and plan identities, full-text fingerprints and C ABI entry points (now 0.20.0). See the [migration guide](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.0/docs/MIGRATION-4.0.md) before upgrading and the [complete changelog](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.0/CHANGELOG.md) for the full change history.
