# PurRDF 4.0.0

PurRDF 4.0.0 updates the shared RDF 1.2 engine and its Rust, Python, JavaScript/WASM and C bindings.

- Exact XSD numerics throughout: integers and decimals of every size share one exact value API, and decimal division keeps every digit of a terminating quotient.
- Datalog gains shared head conjunctions, native inequality and guard values, native integer dictionaries, incremental maintenance across signed transactions and explicit, removable capacity limits.
- SHACL adds the editor's-draft law and typed rule sets, and SRL inference accepts a stop signal. Direct OWL subsumptions and types require a fully decided certificate.
- New `purrdf-glob` and `purrdf-toml` crates add compiled Unicode glob matching and a lossless TOML 1.1 codec; Function Ontology catalogs read and write through one admission path.
- Exact BM25F ranking drops its admission ceilings, and segmented storage moves to data profile 6.
- Named graphs emptied by Update are remembered by default across every surface.
- Canonicalization and canonical identities return typed refusals instead of panicking, and errors across retrieval, Parquet, HNSW, text and CDT retain their original native causes for structured inspection.

This major release changes Rust APIs, persisted segmented stores, Datalog proof and plan identities, full-text fingerprints and C ABI entry points (now 0.12). See the [migration guide](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.0/docs/MIGRATION-4.0.md) before upgrading and the [complete changelog](https://github.com/Blackcat-Informatics/purrdf/blob/rust-v4.0.0/CHANGELOG.md) for the full change history.
