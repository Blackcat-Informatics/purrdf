# Explicit GB 18030 conversion

`purrdf_lex::gb18030::Transcoder` provides strict streaming decoding to UTF-8
and encoding from UTF-8. Select a direction, limits and one complete profile:

- `Profile::Gb18030_2022Amendment1`: GB 18030-2022 with Amendment 1 and all
  reciprocal Annex D.1 changes.
- `Profile::Gb18030_2005`: the separately identified legacy mapping.

There is no default profile, encoding sniffing, replacement-character recovery,
Unicode normalization or GBK/web alias. Byte `80` is invalid, Euro is `A2E3`,
and `A3A0` retains U+E5E5. Removed chart glyphs retain their scalar mappings.
Every Unicode scalar, including noncharacters, is representable; surrogate
spellings and malformed UTF-8 are refused. See the complete
[mapping provenance and grants](../crates/lex/data/gb18030/PROVENANCE.md).

## Chunks, contributions and failure

`push(input, final_input, progress, emit)` accepts any byte boundary in either
direction. A non-final incomplete scalar remains in the four-byte pending
buffer. Final incomplete input is a typed error. Codec state, output order and
all source coordinates are independent of the chunk partition.

Each emission contains one scalar, its output bytes, the exact half-open
original source byte extent and the half-open output byte extent. All emitted
bytes for that scalar have its whole original source contribution. These
profiles contain no one-to-many mappings. An output extent's end maps to the source extent's
end; interior UTF-8 bytes do not become fabricated original boundaries.

The codec allocates nothing. Output and retained source maps belong to the
callback. Original callback and `Progress` errors remain their original types
and owners, including allocation, work and cancellation refusals. Total source
and output ceilings are checked before consumption or emission. Source errors
retain the selected profile, direction, complete offending/pending bytes and
their original extent; UTF-8 errors retain their native cause. The extent starts
at the sequence's lead byte, and a malformed continuation is its last consumed
byte. A refused byte beyond a source ceiling has not been consumed.

A failed stream is poisoned: neither another chunk nor finalization can turn
its accepted prefix into a successful complete conversion. Previously accepted
callback output remains the caller's prefix; an error never claims it complete.

## Native RDF ingestion

`purrdf_rdf::parse_dataset_from_encoded_reader` selects the profile explicitly
through `EncodedReadOptions` and calls the same native RDF grammars and
statement-layer fold as existing UTF-8 ingestion. Existing UTF-8 entry points,
`ParseOptions`, `ParseOutcome` and `RdfLocation` retain their contracts.

The caller supplies original `Memory` admission, `Progress` authority and a
contribution callback. Text and source-map allocations are admitted before
construction, include replacement peaks in the workspace ceiling, and are
destroyed and refunded before return. Per-line limits apply to line grammars;
whole-stream UTF-8 output and conversion-workspace limits always apply.

N-Triples/N-Quads retain the existing CR, LF and CRLF rules. HexTuples retains
the distinct NDJSON rule: a lone CR is content, while LF and CRLF terminate
lines. Conversion retains the current physical line and peeks raw bytes for CRLF.
Its fixed 8 KiB input window can prefetch raw source bytes; it does
not decode the next window into hidden source maps. Reused buffers retain at
most the largest admitted line's capacity. Other grammars keep their genuine
whole-text requirement and retain complete admitted UTF-8 text and maps under
the explicit ceilings. Native grammar state and the returned dataset remain
separate resident resources, proportional to their content.

The new outer `EncodedReadError` retains unchanged native diagnostics and adds
the exact original scalar extent or end boundary when a diagnostic supplies a
position. Native line and scalar-column coordinates stay unchanged. Original
reader, codec, output, memory and cancellation causes travel through their own
typed branches. The legacy formatting-only reader-error conversion is not used
by this path. A failed acquisition or parse returns no dataset.

Ordinary mapping, refusal, split, ownership and memory controls execute natively.
The codec adds no runtime dependency or semantic Cargo feature and uses no host
I/O; the ingestion caller owns its `Read` transport.
