# Focused implementation review

Implementer review only; independent review remains required before landing.

The sole GROUP worker caller selects OrderedRows before dispatch. Existing flat callers retain their original Vec adapter; one generic dispatcher owns bounded blocks versus normal chunks. Original worker Vec allocations move into a small ordered descriptor list, not a full minted-row concatenation. ExactSizeIterator length is the checked sum of those original chunks; empty chunks and decrement/order behavior are covered. Operational worker errors are selected in original order before checked size or descriptor admission; overflow and allocator refusal retain typed failures.

The original ItemLedger/commit_items and admit_rows homes consume the exact-length iterator. They still admit typed output capacity before invoking row conversions, re-intern cells in original group order, and retain ordered fuel/scratch replay and continuation boundaries. No oversized input capacity is retained: the existing capacity rule is unchanged. Other flat callers keep their original allocation shape and do not pay ordered-descriptor allocation. Native and actual portable controls cover refusal, ownership, ordering, numeric values, continuation and full receipts; production counters are separate acceptance.

The first candidate count record did not improve traffic. Actual production instrumentation then proved ordinary resident GROUP reaches the safe worker branch with 5000 groups in every numeric lane. Diagnostic sampling showed the expected roughly 400 KB reduction. All probes were removed, source is clean at the same 13dd0b009, and a normal unchanged-configuration rebuild completed 0. Twelve unprobed numeric samples all reduce requested traffic with identical retained bytes and exact-answer guards. Full artifact-bound counter collection is in progress. The initial inconsistent candidate record is superseded, not rewritten or represented as a pass; its discrepancy is not assigned an unverified root cause.

For ungoverned 1/4/32 samples, the reductions correspond to eliminating 5000 minted elements while retaining only 4/17/129 original-buffer descriptors: 399904/399592/396904 bytes. This calculation describes the observed implementation, not a substitute for complete shared collector comparisons or independent judgment. No timing acceptance is used.
