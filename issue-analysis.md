# Scope analysis

The new requirement is a borrowing ownership choice for the already prepared native checker. Every returned context must retain the exact consumer input identity, clause contract, source preparation and stop signal. Existing contexts that outlive their reasoner still need ownership. Both forms must execute the same checker. This issue does not permit checking against producer search state, inventing local contradiction ownership or replacing source-premise extraction with node identity. The implementation will wire the actual native validation caller, not just add an unused API.
