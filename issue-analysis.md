## Required behavior

1. **Connected bodies do not become Cartesian intermediates.** In the reported `A(?v), E(?v, ?s), B(?s)` shape, after `A` binds `?v`, select `E` before the disconnected `B`. Connectivity means sharing a bound variable in any of the four carrier positions, including predicate and graph. Equal constants, including the default graph, are not connectivity. Start another component only when the current component has no remaining connected atom. Cover acyclic and hybrid/certified-cyclic execution paths; a repair only to the acyclic helper leaves production alternatives exposed.
2. **Genuinely disconnected bodies remain factorized.** Evaluate independent components separately. A head depending on only one component must not enumerate their product; other nonempty components provide existential witnesses. A constant head needs existence, not an exhaustive product. A head depending on several components may require the output product, but must combine it at head production rather than materialize a full body product. Preserve semi-naive eligibility: combinations with at least one new premise are eligible, while entirely old combinations are not newly fired. Shared outer variables in negation or guards may couple apparent components and must be accounted for.
3. **The three supplied rules complete at the existing default limit.** `single`, `pair`, and `notype` must exhibit linear time and peak resident memory over 1,000 through at least 100,000 vaults without raising `--max-join-steps`. The input contains exactly seven triples per vault. Expected inference counts are N, zero and N respectively. Validate output contents, not only a successful exit. The acceptance is about the production `purrdf rules --srl` path, not a lower-level benchmark alone.
4. **Proofs retain their semantic content.** Preserve authored rule numbers and premise order when execution order changes. Compare explained facts and selected derivations on representative cases and input permutations. The existing total witness order is minimum `(proof height, summed source heights, sorted source facts, authored rule index, authored source facts)`; component-local choices must implement that global law rather than choose an arbitrary first witness. A competing component can mask local maximum heights, so a locally best witness is insufficient. Saturating proof-height and sum arithmetic need adversarial cases. If an intentional observable correction or changed budget report is necessary, record it, test it and version the appropriate identity.
5. **Metering cannot leave evaluator-owned expansion unbounded.** New factor/head combination, guard-row consumption and relevant negative expansion must check admission before cloning bindings, constructing computed surfaces or appending candidates. A round cannot grant every rule the whole remaining budget and call the resulting rules-times-budget expansion bounded by the caller's limit. Preserve deterministic refusal and completed reports across worker counts and authored error ordering. Existing callbacks return allocated vectors: limiting their consumer does not prove that the producer is physically bounded.
