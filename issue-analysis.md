# #492 independent issue analysis — 2026-10-13

Issue #492 is wholly open. Its body requires an additive graph-free RDF 1.2 carrier, 12-byte base rows, three base orders, compact statement rows, a genuinely three-position Datalog relation, typed named-graph refusal, default-graph SPARQL/RL parity and canonical/text identity. The one approved design comment makes full physical storage, rules and consumer identity one delivery; an arity-four wrapper or foundation-only PR is not completion. This review used the captured issue and current source; it ran no build or forge request.

| Contract | Current production home and implementation/acceptance consequence |
| --- | --- |
| Physical rows and statement layer | `ir/dataset.rs` currently stores 16-byte `QuadRow`, graph-bearing `ReifierRow`/`AnnotationRow`, six indexes and a frozen term arena/index. `ir/builder.rs` accumulates quad/graph rows, validates before materialization and owns rollback/admission. Extract the original frozen term owner and its resolve/reverse lookup once; a triple builder must accumulate 12/8/12-byte rows without transient quad tables. Assert sizes and count actual row/index bytes on nontrivial RDF 1.2 data. |
| Named-graph boundary | `DatasetView` has infallible `named_graphs` enumeration but operational `read_error`, `reserve_workspace`, `checked_read` and `FallibleDatasetView::operation_status`. The frozen triple payload cannot honestly implement the resident infallible door. A fresh `TripleRead` must share one sticky typed cause across iterators/guards/children, latch direct named scans before output, and expose an explicit support preflight at the actual engine and dataset-spec entry paths before missing-term or empty-input shortcuts. An empty quad dataset is still capable of named graphs; capability must describe support, not observed content. |
| Datalog and RL | `plan.rs` fixes `ATOM_ARITY=4` and `[PositionPlan;4]`; `store.rs` keys partitions by `(predicate, graph)` and `seminaive`, chase and proof read graph position. Closed compile-time shape must cover planner, SIPS, row log, arrangements, chase/proof/model identities and entail egress, using the S1 dictionary-parametric ID waist and one evaluator. Demonstrate actual arity-three compiled atoms/predicate-only keys and public RL parity on recursive and variable-predicate fixtures. |
| Canonical and text identity | `ir/canon.rs::try_canonicalize_flat_view` and `try_flat_digest_view` already share the fault-aware flat assertion presentation; compare that same presentation on triple and all-default quad views, including statement data. `text/index.rs` stores graph in `PartitionKey`, `Document` and internal keys, while `ranking.rs` fixes the graph-language profile ID. A distinct graph-free subject-language profile must omit graph from physical keys and fingerprint, while reusing analyzer/ranking and preserving the old profile. |

Acceptance must include the unchanged default-graph portion of the official SPARQL corpus with manifest-derived inventory/XPASS, actual native and WASM execution, complete affected gate and protected integration. No existing source or prior-art result establishes any of these new #492 outcomes yet. PR #544's published S1 source is an interface dependency, not #492 qualification.
