# Metered recording implementation in progress

## Current source and qualification

The final implementation uses the same governor accounting engine and cost law: one mutex-owned ChargeLog, unchanged fuel/growth/transient ordering, redundant unchanged-growth coalescing, and empty shared-arena flattening. One common representable-row Layout predicate removes unreachable cell cuts while preserving every observation and forecast. Newly eligible parallel join/OPTIONAL emissions, ordered concatenation and final admitted output use the existing fallible reserve homes and preserve first recorded source error. The scratch-only resume latch repair and actual retained-prefix continuation are independently qualified without changing the original physical peak formula.

The complete first count matrix meets the numerical instruction criteria and all full SUM/evidence guards, with owned allocation increases recorded. It remains source-bound evidence for the candidate before BIND/Group buffer repairs. Parked selected-worker counting now passes all37 targets at1/4/32; the original aggregate witness is superseded. BIND ownership/public equivalence and lint pass, with its extra allocation removed in the first repaired query window. Group reuse, charge-buffer/live-arena attribution, final paired counts and affected production/host checks remain open. count-progress.md indexes exact sources, artifacts and results. Prior functional/physical/profile/native OPTIONAL/CLI/Wasm receipts and elapsed observations retain their recorded source identities.

## Historical implementation and diagnostic record

The entries below describe their recorded earlier source snapshots and experiments. Earlier pending or failed statements are historical, not final qualification.

The numeric group benchmark now obtains actual typed solution rows from every production call before timing, canonicalizes GROUP BY's unordered bag and compares all cells with the plain answer. The timed query bodies and dataset are unchanged. Main's pre-existing harness proves only completion/count; candidate full-value validation strengthens that evidence without editing detached baseline source.

Profiling identified recorded worker charge overhead. ExactDeferral now records an arena Growth checkpoint only when its computed count changes: a repeated checkpoint charges zero bytes, while every new count and every refused fuel/scratch charge mark remains in order. Item boundaries read the recorded length and reset the per-item counters under the same ChargeLog mutex. The governor's shared observable counters and cost law are unchanged.

The lightweight recording candidate did not meet the ratio (4-worker 18.35/11.92 ms, broad 17.20–20.24 ms interval). ExactDeferral now keeps its mutable counters and ordered entries in ChargeLog under the existing mutex. Every public deferred charge delegates to that one log implementation. An exact operation on its own worker arena holds the log once across the same fuel, growth and transient sequence; its stop poll occurs first. A derived child arena retains the original fuel → claimed child growth → transient ordering. No observable shared GovernorState counter or cost law changes. The repeated-growth and item reset optimizations remain inside the log, using ordinary mutable state under that ownership lock.

The internal checks cover repeated growth across an item boundary, fresh mints, refused charge marks, saturation and equivalence of batched versus separate numeric admissions at every refusal boundary. The numeric determinism matrix now includes 4 workers and metered completion alongside finite fuel/scratch limits, inspecting all consumed dimensions, expression errors and full answers; complete fuel and scratch boundary neighbors were added.

The counted high-cost-row witness initially failed. Moving a counter from AND into IF did not repair it. raw/physical-witness-probe.log proves 16,389 visits over a 16,384-row input at 4 workers and ~883 KB scratch, with the window closed before observation serialization. Source diagnosis and independent reviewer agreement identify a real resume bug: a scratch-only sequential RowCheckpoint was Free, so after a conservatively stopped worker resumed, its eventual scratch trip did not stop subsequent row starts. Those rows ran the native callback and populated the numeric parse cache. for_rows now gives scratch-engaged sequential evaluation the existing Sequential checkpoint; it observes the latch before the next row and adds no fuel when fuel is disengaged. The original peak/work bound remains unchanged. raw/focused-governor-tests-resume-fixed.log passes 25 governed-query, 9 correctness, 12 numeric-governance and 9 numeric-determinism tests. At ~883 KB scratch, the 4-worker witness has 8 visits/3.49 MB peak and the 32-worker witness 36 visits/11.88 MB peak. The final stronger independently calibrated input/per-row bound is pending rerun.

The batched 32-worker formal benchmark did not meet acceptance: metered/plain medians 14.41/11.67 ms = 1.235, above 1.20. Its cycle profile (raw/candidate-batched-metered-32-profile.txt) records charge_fuel at 1.48% and charge_numeric at 1.36% self, with the old record symbol gone. Shared GovernorState charge_work is not a measured hotspot.

An inline-hint experiment initially measured 18.69/10.59 ms, but same-host forward/reversed comparisons contradict a stable code effect. Forward: batched 18.00/12.72 ms, inline 14.35/10.75 ms; reversed: inline 15.54/11.18 ms, batched 14.87/10.78 ms. The hint-only optimization has no stable material benefit in those measurements and is removed. Every ratio remains above 1.20. Receipts: raw/candidate-inline-numeric-group-32.log, raw/interleaved-{batched,inline}-numeric-32.log and raw/reversed-{inline,batched}-numeric-32.log. These are failed or inconclusive experiments, never passing final acceptance.

ScratchInterner::over now omits an empty ancestor pointer when the snapshot computed_count is zero. It keeps the snapshot clone, copied minted-byte/blank-label/tracking state and fresh local index/charged/ghost state unchanged. Zero stored terms makes ancestor lookup inert; new IDs, deferred growth, ordered harvest and parent ghost reconciliation are the same. The rejected direct-clone shortcut would duplicate a retained empty HashTable per worker; this over-only change instead retains the single snapshot allocation and fresh empty worker table. raw/empty-shared-arena-test.log passes the actual retained-index reuse fixture, inherited mint/label state, exact IDs/full term values/growth/ordered harvest, parent ghost dedup and nonempty Arc sharing. The read-only reviewer inspected that proof and fixture. Full final-source physical/governor refresh and formal performance remain pending; the new candidate is built and being measured without concurrent compilation.

The next measured source finding is the common cell-row ceiling. METERED engages cells at MAX-1; on a 64-bit target its row quotient fits usize but cannot form the outer Vec<Solution> allocation. This was selecting the cell-bounded sequential BGP driver. An isolated BGP-only layout experiment consistently reduces four-worker numeric metering from 16–18 ms to 13 ms, about 1.04–1.06 times plain in both run orders. The 32-worker reversal was not accepted as qualification and is not acceptance. The shipping plan, independently reviewed in reviews/cell-layout-plan-review.md, uses one Layout::array predicate in EvalCtx::cell_row_ceiling, leaves all engaged observations and forecast admission intact, preserves real inclusive cell bounds, and retains typed output allocation failures in newly parallel joins/OPTIONAL and ordered concatenation. No packet representation change is being made. All worker and resumed matched/wild/scan/padded pushes use the existing reserve_join_rows home; source-ordered operational errors must be selected before checked output sizing/reservation.
