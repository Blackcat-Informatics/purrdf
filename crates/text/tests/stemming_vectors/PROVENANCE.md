# English stemming specification and reference data

`../../src/stem.rs` independently implements the prose sections
“Definition of the English stemmer” and “Exceptional forms in the English
stemmer” of the [English Snowball specification](https://snowballstem.org/algorithms/english/stemmer.html).
The declared algorithm version is **Snowball 3.1.0**, identified by release
commit `77e07c9c19b89266632b47a4321b33f2106135bb`. No upstream implementation
code is incorporated. The Rust implementation and its scalar/Latin domain law
are offered under `MIT OR Apache-2.0 OR MulanPSL-2.0`.

The implementation holds scalar letters and their vowel classifications,
fixes region offsets before suffix processing, and applies longest-matching
suffix rewrites under explicit region and predecessor conditions. Non-ASCII
Latin letters that survive the caller's normalization are non-vowels. At least
one Latin letter is required and every letter must be Latin; other words are
preserved. The caller selects English stemming and supplies folded text.
This law is named `snowball-english-3.1.0-latin-scalars-v2`.

`voc.txt` and `output.txt` are the complete, unmodified official English test
corpus from [snowball-data](https://github.com/snowballstem/snowball-data/tree/a0ec0d0a2839ec885878868de20fcb63209d92b0/english)
at commit `a0ec0d0a2839ec885878868de20fcb63209d92b0`. Each contains 42,649
corresponding lines. Every line is exercised by `../stemming.rs`, through both
public APIs. Expected outputs are never regenerated by PurRDF.

All but three inputs contain ASCII Latin letters. The three remaining inputs
are one, two and three apostrophes. The third is the corpus's sole intentional
domain divergence: raw Snowball produces one apostrophe, whereas this profile
preserves all three because the input has no Latin letter. The test asserts
both the unchanged frozen reference answer and the profile's preservation law.
All other 42,648 reference answers are required exactly.

The data retains its BSD-3-Clause copyright and license in
`LICENSES/Snowball-data-BSD-3-Clause.txt`; `REUSE.toml` records these terms.
These terms permit redistribution alongside every offered code license, with
that data notice retained. They do not relicense the first-party algorithm.
