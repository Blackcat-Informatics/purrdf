# Provenance of `purrdf-text`'s Unicode data and frozen vectors

The code under `src/` and `examples/` is first-party, written from the Unicode
specifications: UAX #15 (Unicode Normalization Forms), UAX #29 (Unicode Text
Segmentation, word boundaries), the Unicode core specification chapter 3
(§3.11 normalization forms, §3.12 conjoining jamo behavior, §3.13 default case
algorithms) and UAX #44 (the file formats). What the crate carries from
elsewhere is data, recorded here.

## `src/unicode_tables.rs` — generated from the Unicode Character Database

- Generated by `cargo run -p purrdf-text --example gen_unicode_text_tables`
  from the Unicode 17.0.0 files vendored under `crates/iri/unicode/17.0.0/`
  (`UnicodeData.txt`, `CompositionExclusions.txt`, `DerivedCoreProperties.txt`,
  `CaseFolding.txt`, `WordBreakProperty.txt`, `emoji-data.txt`); see
  `crates/iri/unicode/PROVENANCE.md` for where those files come from.
- License: the data is Unicode's, under Unicode-3.0, and the file carries both
  licences in its SPDX header.
- Held to the generator by `scripts/check-generated.sh`.

## Conformance data read by the tests

`tests/unicode_conformance.rs` reads `NormalizationTest.txt`,
`WordBreakTest.txt`, `CaseFolding.txt`, `DerivedNormalizationProps.txt`,
`DerivedCoreProperties.txt` and `UnicodeData.txt` from the same vendored
directory, and `tests/unicode_differential.rs` reads the 16.0.0 and 17.0.0
`CaseFolding.txt` to compute where the fold changed between them.

## `tests/*_differential_vectors.txt` — frozen answers

Answers only, no code, recorded before the analyzer's third-party Unicode
crates were replaced; each file's header names the crate and version its
answers came from, and carries a SHA-256 of its body.

- `case_fold_differential_vectors.txt` — the full case fold of every scalar
  value that does not fold to itself (`CaseFolding.txt` 16.0.0).
- `normalization_differential_vectors.txt` — NFD, NFC, NFKD and NFKC of every
  scalar value that is not its own form under all four (Unicode 17.0.0).
- `word_differential_vectors.txt` — word indices and analysis forms of the
  100,000 inputs `tests/support/unicode_inputs.rs` generates.

The replay and every admitted disagreement, each with its reason, are in
`tests/unicode_differential.rs`.

## Recorded caseless-match verdicts

The equivalence classes in the analyzer unit test
`the_form_decides_compatibility_caseless_matching` (`src/analysis.rs`) are
verdicts of an independent compatibility caseless match, recorded over every
pair of that test's samples: answers only.
