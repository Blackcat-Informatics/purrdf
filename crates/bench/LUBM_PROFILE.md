# Native university corpus

`purrdf-lubm-native-v1` implements the [published university data profile](https://swat.cse.lehigh.edu/projects/lubm/profile.htm) with an original sampling law. It does not reproduce UBA's random sequence or historical answers.

A university stream starts at `splitmix64_finalize(seed ^ splitmix64_finalize(index))`, then uses `splitmix64_next`. Inclusive integer draws reject values below `(-width) mod width`, then reduce modulo width. All arithmetic is unsigned, with wrapping confined to the specified stream. Each university is independent of its range, output path and locale. Draw order follows the emitter: department count, each department's staff counts, per-faculty courses/publications/degrees, population totals, students and assignments. Discrete populations use uniform inclusive ranges. Fractional lower bounds round upward, upper bounds downward; the exact one-fifth undergraduate advisor population rounds downward. TA upper bounds additionally respect available distinct courses. Selections without replacement use a partial Fisher–Yates shuffle. TA and RA selections are independent and may overlap. Each graduate coauthor selects distinct professor-owned publications. Faculty publications have exactly one original faculty author; additional graduate authors do not change faculty publication counts.

Department documents are named `University{index}_{department}.nt`. Instance names use `http://www.University{index}.edu` and `http://www.Department{department}.University{index}.edu/`. Schema namespace is the explicitly selected ontology IRI plus `#`; the caller-selected document base ends in `/` and supplies the document ontology identity. Each file carries an owl:Ontology type and owl:imports. Degree origins use explicitly typed `http://www.ExternalUniversity{0..999}.edu` references, distinct from generated university ownership. Course, person, publication and group indexes are department-local. Publication authors point from publication to person. Department/group organization links point toward their parent; heads point from full professor to department. Student, Professor and Chair classes are inferred, never asserted.

Each department is streamed through the shared lexical term writer. A fresh output directory is required. No existing path is overwritten. The sorted typed JSON receipt binds profile, seed, university range, ontology, document base, names, byte lengths and BLAKE3 digests. It is created only after every nonempty payload is flushed and reread. Failed runs retain their owned partial files without a valid receipt. The receipt is a byte identity, not a graph-conformance claim.
