# RFC 5646 `Language-Tag` differential acceptance table (frozen).
#
# WHAT THIS IS
#   One line per candidate tag: `<verdict>\t<encoded input>`, where <verdict>
#   is `accept` or `reject`. `crates/iri/tests/langtag_differential.rs` asserts
#   that `purrdf_iri::langtag::is_well_formed` returns exactly this verdict for
#   every line. It exists so the claim "the first-party parser's acceptance
#   language is identical to the dependency it replaced" can go RED, instead of
#   being unfalsifiable prose.
#
# WHERE THE INPUTS CAME FROM (independent of any implementation)
#   * A systematic sweep over the RFC 5646 §2.1 ABNF: each of the seven
#     `langtag` sections (language, extlang, script, region, variant,
#     extension, privateuse) has an option list covering its admissible shapes
#     and its length/character boundaries, plus impostors just outside them.
#     Swept as (a) a full cartesian product over a reduced option set, (b) one
#     axis at full breadth in three surrounding contexts, and (c) every
#     adjacent axis pair at full breadth.
#   * The closed grandfathered list of RFC 5646 §2.2.8, with case variants,
#     truncations, and one-subtag extensions.
#   * The worked examples of RFC 5646 Appendix A, with case variants.
#   * Structural inputs: empty string, hyphen placement, over-length subtags,
#     non-hyphen separators, non-ASCII, and C0 controls.
#   No input was taken from any implementation's own test corpus.
#
# WHERE THE VERDICTS CAME FROM
#   Labelled once by `oxilangtag` 0.1.6 (`LanguageTag::parse(input).is_ok()`),
#   used purely as an external oracle over the independently generated inputs
#   above. No upstream code and no upstream test data was read or copied. The
#   oracle crate is not, and must not become, a dependency of this workspace.
#
# ENCODING
#   `\\` is a literal backslash, `\xHH` is the byte HH (used for the space
#   0x20 and for C0/DEL controls), and a lone `\0` is the empty input. Every
#   other byte, including non-ASCII UTF-8, is verbatim. Lines are sorted by the
#   raw input and are unique.
#
# TAMPER EVIDENCE
#   Regenerating or editing a verdict changes `body-sha256`, which the test
#   recomputes. Reproduce externally with:
#     grep -v '^#' <this file> | sha256sum
#   A mismatch between this table and the parser is a PARSER defect. Do not
#   "fix" it by editing the table.
