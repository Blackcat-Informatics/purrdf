# Algebra admission draft integration

`algebra-admission-draft.rs` is proposed Rust for a child module of `engine::bounded_workspace`. It uses the source writer's current `try_walk_pre_post`, concrete `WorkspaceCapability`, `WorkspaceAllocation`, `workspace::vector`, `workspace_candidate_bound` and actual `Solution<I>` layout. It has not been compiled, formatted or tested, and shipping source is unchanged.

The coherent unit is exhaustive Query/GraphPattern traversal, admitted traversal/schema-reference metadata and optional **uniform** row certificates. It visits nested terms, aggregate/order/EXISTS children using the one algebra walker. Borrowed first-seen variable columns match current `syntactic_schema`; expression-private columns do not leak. Row certificates preserve unit empty BGP, exact zero, VALUES bags, OPTIONAL padding, Apply retry law, global aggregates and bounded Slice. Full-stream metadata is separate from heap bytes. Fixed-path sequence/alternative retain bag products/sums; repetition and unverified native/resolver sizes stay Unknown and use local growth. Graph declaration count is never inferred from quad count; an empty declared graph's empty BGP remains a unit. FROM NAMED-only default is zero, merged FROM uses a safe complete-stream superset without repeated-graph multiplication.

Integrate with the existing owned reporting/account creation; do not create another account for this traversal. Keep metadata guards until metadata drops, and project any charge refusal through the shared account's first typed error. `GRAPH` inside a remote `SERVICE` scope keeps that remote scope; local named-graph stream bounds must not certify its children. The helper `bag_layout` consumes actual selected row/spill capacities and excludes term payload/schema/hash layouts deliberately. Never treat the certificate's borrowed columns or optional row bound as a complete physical execution fee.

Mandatory source owner hooks are explicitly listed at the draft's end. They remain real work: compiled constants/probes/planner, active-dataset and schema tables, every real BGP prefix, joins/row spills/correlated blocks, paths, VM/computed values, modifiers/aggregates, admitted producers/remotes and all four publication owners. The writer must connect these before removing the old shape/context guards or claiming bounded support. No magic text multiplier, Cost saturation or stored-term-size multiplier is proposed.

Known limitations: the draft does not perform constant reverse lookup or classify absent ground graphs; its full-stream counts are safe upper bounds, not selectivity estimates. It does not enumerate named graphs when no cheap certified declaration count exists because `named_graphs` can itself allocate a BTreeSet. Repetition/frontier and native producer bounds are intentionally Unknown. Query templates/targets are borrowed at this layer and belong to actual CONSTRUCT/DESCRIBE pre-growth hooks. Service/driver schemas can exceed known syntactic columns; actual schema construction must admit them. Per-node borrowed-column unions use linear membership checks to preserve actual first-seen order without an unpriced hash table; the writer may share a certified existing schema builder instead.

Qualification after integration: existing real-entry empty/default/named graph and virtual-stream tests; all algebra/form/prebinding/correlation cases from the certified packet; fixed-path bag alternatives/sequences; metadata allocation denial and optional row-product overflow followed by selective execution; all mandatory owner families under allocator/resource denial. These are focused cases within the one coherent delivery, not a request for another full-gate invocation or review campaign.
