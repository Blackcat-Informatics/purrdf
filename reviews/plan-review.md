# Owner plan challenge

This is an owner review under the explicit zero-subagent instruction, not an
independent approval. The plan includes every issue criterion and the production
DatasetView, statement and planner consumers. It does not treat the first index
unit as a complete issue. Current source confirms the proposed reuse homes.

Required design checks identified before implementation:

1. A low callback candidate count cannot prove that an annotation probe avoided
   scanning. Inspect actual access selection and instrument physical candidate
   reads in the scale control; do not count only residual matches.
2. Both query index warming paths and retained-byte certification must include
   every added lazy order before graph publication. The graph-free physical
   row layout remains unchanged.
3. Partial triple probes may return a conservative candidate superset for scan
   backends. EXPLAIN must describe that truth; filtering exact nested structure
   remains the existing binding home's job.
4. Index order can affect deterministic un-ordered results and fuel traces.
   Preserve specified ordering or explicitly reconcile the versioned governor
   receipts and conformance rather than changing expectations blindly.

No additional scope or prerequisite approval is needed to implement the plan.
Independent source judgment and final acceptance remain unverified until
publication and actual qualifying evidence exist.
