## Remaining confirmed defects

1. **ORDER BY sampling uses aggregates anywhere in the query instead of aggregates in its own clause.** `parser/machine.rs` around 2318 saves `had_aggregates = !aggregates.is_empty()` before sampling and uses it for all ORDER expressions. Genuine translation checks that ORDER clause itself. For `SELECT (COUNT(*) AS ?n) (?x AS ?this) WHERE { VALUES (?x ?y) {(1 2) (2 1)} } GROUP BY ?x ORDER BY ?y`, genuine ordering retains this=1,2 because y is not sampled. Current lowering introduces Sample(y) because projection COUNT exists and consequently sorts 2,1. HAVING aggregates likewise must not trigger plain ORDER sampling. `raw/group-order-clause-local-sampling-oracle.json`, SHA-256 `c1c042a450c52e070d9f33f2475cf207e1edc0390fd391ffee5cc6912d861107`, contains six genuine 7.6.0 ordered answers, including ORDER(COUNT()+y) as the contrasting positive sampling control. Required repair: clause-local aggregate detection and permanent ordered controls.

2. **Nonlazy JOIN and MINUS lose producer/consumer delivery and stop at their left boundary.** Compiler lowers these to ordinary Join/Minus. `eval_node_with` does not list either in streamed dispatch; their arms invoke eager `eval_join`/`eval_minus`, which materialize left before downstream delivery. For `SELECT ?tick WHERE { {SELECT DISTINCT ?tick WHERE { VALUES ?x {1 2 3} BIND(<http://example.org/counter>(1) AS ?tick)}} VALUES ?y {0} } LIMIT 1`, genuine nonlazy Join eagerly constructs RHS but lazily consumes LHS: exactly one callback and tick=1. MINUS with disjoint RHS has the same left-stop rule. Grouping above these operators must interleave left BIND and aggregate updates: input sum=9, aggregate sum=12, six calls, rather than materializing left calls first. `raw/join-minus-delivery-oracle.json`, SHA-256 `4583c4c43ded71e4b4ae714430fa1e077d3e2b7b944e248aaaf851073376ad2b`, contains eight genuine 7.6.0 cases with/no initial bindings. Required repair: contextual delivered JOIN/MINUS retaining their nonlazy RHS set/domain laws and shared error/resource/extension handling, plus stop and aggregate-interleaving controls. The existing 213-case callback census has no such boundary witness.
