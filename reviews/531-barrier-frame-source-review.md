# #531 barrier frame boundary: independent source and artifact review

**VERDICT: SOURCE-BOUND CAUSAL CANDIDATE, NOT A MEASURED CORRECTION.** Read-only review of committed `expr.rs`/`shapes/barrier.rs`, the retained symbol-bearing raw WASM disassembly `531-exists-raw-frame-root.txt` (raw SHA `df06f76902bd31d251d4d7749be3f8356ce52cfb06fb25f0e75cf980c58a5dd8`), `T3-531-barrier-inline-source-readback.md`, and original nested NOT EXISTS test source. Current worktree has only the separate dirty `binop.rs` LATERAL partial correction; `expr.rs` is restored. No build, source/tooling edit, or new floor claim was made.

The raw `exists_prepared::<RdfDataset>` reserves 3,952 WASM stack bytes. It separately calls `exists_positive_seeded` at `0x1a54321`. Its `0x1a57543`–`0x1a575fc` region includes row-builder finish/retained-row cleanup and addresses offsets 3,892–3,928, before the definition path's direct `eval_correlated` call at `0x1a578c7`. In source, `exists_prepared` calls `shapes::barrier::inner` immediately before that fallback; the latter contains the row builder and retained-row loop, and the raw symbol table has no standalone `barrier::inner::<RdfDataset>`. This makes inlining of the large barrier body into the recursive caller a **well-supported inference**, though the disassembly does not prove the exact size of each Rust subexpression or the linked package's final frame.

The original deep workload is repeated `FILTER NOT EXISTS` over a walk, not the native positive fast path. Each definition-path `eval_correlated` enters a substituted-evaluation window. `barrier::inner` returns `Ok(None)` at its first condition when `ctx.in_substituted_exists` is true, then `exists_prepared` falls through to the recursive `eval_correlated`. Thus a large inlined barrier branch can enlarge every compiled caller frame even when that branch is skipped at these nested levels. A single `#[inline(never)]` on the **existing** `barrier::inner` is a bounded way to move that branch's frame out of `exists_prepared` while leaving result, admission, ordering, owners and allocation code untouched. The separate call may itself use stack, and barrier queries that actually enter the body can recurse within it; neither outcome may be assumed harmless without the original controls.

This proposal has more causal support than the three rejected extractions: collision admission, memo probe and postchild finish changes all left the original NOT EXISTS slope at **7,104 bytes/level** and the original floor at **133 < 180**. Their failures do not prove this boundary will succeed. Inspect the exact one-attribute diff, run the existing native shape/barrier/EXISTS behavior and governance controls, then measure a fresh optimized package against the unchanged 7,104-byte slope, deepest-answer/first-refusal floor, synchronous/job parity, typed refusal and post-refusal health. A smaller raw frame alone would not be acceptance; the linked package must meet the original floor. No floor, stack budget, test or toolchain should change. #531 and #470 full package gates remain FAILED/OPEN until actual terminal evidence says otherwise.
