# Dynamic copied-child cursor review — 2026-10-13

VERDICT: BLOCKED on copied-depth cost. The measured 20/40/80 same-input counts of 400/1600/6400 root-prefix steps prove quadratic work in the dynamic copied-child route. The new lexical owner borrow in `eval_ordinary_chain` is source-sound for a copied root present at entry, but `schedule_exists` and `schedule_lateral` replace `runner.copied_owner` *inside* `eval_ordinary_borrowed` and set `current = Copied { depth: 0 }`; that path still resolves each entered/returned position through `NodeRef::at_path(owner, prefix)`. The lexical wrapper cannot by itself fix the measured LATERAL-right copied child.

The current `PreparedPattern` owns a `SharedWorkspace<CorrelatedPattern>`; `CorrelatedPattern` owns a `Box<GraphPattern>` and its original allocation frame. The AST body is immutable, and moving or shallow-cloning the shared owner does not move its boxed node addresses. `PlanShape` only maps address to `NodeId`; it cannot reverse-resolve a child. A safe `&GraphPattern` held in a movable `OrdinaryRunner` alongside the owning `PreparedPattern` would be a Rust self-reference, so the simple outer lexical borrow only applies to owners known before runner construction. Re-entering `eval_ordinary_chain` recursively at each dynamic child would recover a borrow but restore the stack-depth failure this driver is meant to remove.

The smallest coherent direction is one owner-backed immutable cursor at the existing `PreparedPattern`/ordinary-position home, not a new AST or evaluator: hold the shared owner for the entire dynamic child interval; derive a child address from `NodeRef::for_each_child` while the parent is valid; retain that exact address in the suspended position; resolve it in O(1) only while the matching owner is retained. This likely requires a narrowly encapsulated unsafe pointer internally because Rust cannot express the runner's movable owner/descendant borrow. Do not expose an arbitrary pointer constructor or permit pointer arithmetic. The cursor must prove: (1) the pointer comes only from a node of its own immutable boxed root; (2) shallow owner clones and moves preserve that node's address; (3) nested owner replacement and parent restoration retain the right owner in each pending frame until its last cursor and scope token are gone; (4) active `NodeBoundary` aborts and copied/ledger scope tokens restore in LIFO order before the owner drops on error or panic; (5) no cursor is dereferenced after last-owner release; (6) owner clone/reference-count refusal and frame admission occur before installing a child scope, preserving the first error. Preserve the borrowed ordinary route without new allocation.

An owner-index plus raw-address cursor held only in the runner could avoid per-node shared clones, provided the owner registry is admitted before publication and an index cannot be reused while any frame still names it. Alternatively each copied position can retain a shallow `PreparedPattern` clone, but that changes per-node control/refcount cost and must be measured. No subtree clone, flat AST rewrite, unsafe lifetime extension, or separate traversal implementation is justified. Keep `NodeRef::for_each_child` as the sole child-selection traversal; removing the root-prefix vector and its admission is valid only after exact pointer/owner and unwind proof.

Required acceptance after a source correction: rerun the same input 20/40/80 visit counter on the actual LATERAL-right copied route and nested EXISTS/LATERAL; show near-linear child selection, check clone/last-owner and caught-unwind release, preserve row/evidence/first-error behavior, and run original optimized WASM depth floors. A changed source shape or successful compiler check is not a cost or stack-floor result. No build or production change was made in this review.
