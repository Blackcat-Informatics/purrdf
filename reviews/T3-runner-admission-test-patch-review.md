Keep the real output admission available and test the relevant pending-frame/box increments specifically; the structural `OrdinaryRunner { first: None, pending: AdmittedVec::new(..) }` already proves no initial pending backing buffer. Do not change production output admission to satisfy this test.

This is especially relevant when the same evaluator path has schema/row/control admissions before suspension. After applying the test, verify each selected target against the actual caller order; a named caller checkpoint or source-backed uniqueness argument is needed before saying the refusal happened at that precise construction. The checked context fields show no copied scope survived, but do not locate the refused charge.

Keep the positive assertion and use the narrower wording.
