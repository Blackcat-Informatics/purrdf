# Resident capacity proof for the logical-panic census — 2026-10-13

**Recommendation: a narrow, fail-closed proof ledger for exact reconstruction sites, backed by source-shape fingerprints of their producer invariants.** Do not exempt a function name, `from_index`, an `expect` message, or a whole read API. The current local syntax visitor cannot establish that a value read from one owner's index was minted by a different method; treating all such reads as errors would reject valid resident reconstruction, while recognizing the wording of `expect` would hide future mint bugs.

The source establishes three distinct reusable facts:

1. **Resident local term owner.** `builder.rs::Interner` has private `terms: Vec<InternedTerm>` and `index: HashTable<u32>`. Its miss path calls `LocalCapacity::required(LocalTerms, len, 1)`, converts the old length to `u32`, and calls fallible `TermId::from_index` before inserting that ordinal. Native limit is `u32::MAX` terms, so every stored or enumerated index is strictly below the reserved `u32::MAX` index. `RdfDataset` keeps the frozen term table/index, and its concrete `term_count()` returns that vector's length; its clone copies both. Thus a concrete stored index or `0..term_count()` enumeration can reconstruct the same `TermId`. This does **not** prove arbitrary `DatasetView::term_count()`, foreign provider counts, new intern calls, or `term_count()+1`.
2. **Resident global term owner.** `global.rs::GlobalDictionary` owns private `terms: Vec<GlobalInternedTerm>` and `index: HashTable<u64>`. The miss path checks `GlobalTerms` against `u64::MAX` and uses `checked_from_index` before insertion. Stored hash indices reconstruct from that owner. The lazy value index enumerates the same non-zero-sized resident vector; on supported pointer widths its addressable element count is below `u64::MAX`, so the niche terminal index cannot occur. This does **not** prove an arbitrary global ID or remote logical interval.
3. **Segmented interval.** `SegmentedBuildLimits::with_first_term_index` checks `first + terms` without overflow; the builder admits actual terms below `limits.terms`. Therefore `first + local.index()` for an admitted term is strictly below the checked endpoint, including when the endpoint is `u64::MAX`. `map_id` is valid only for that bounded dataset/builder and those limits. The `from_pack_v1` path checks source term count against limits before `encode_dataset`; `seal` freezes the bounded builder. A generic `map_id(id, first)` call has no such proof by itself.

**Smallest checker mechanism.** Keep the rule's default hit. Add a checked proof table inside the existing `logical-capacity-panic` job with one row per exact call-site AST identity (path, enclosing item, normalized call expression, expected unique occurrence) and a named proof class: `local-stored-index`, `concrete-frozen-term-range`, `global-stored-index`, `resident-global-vec-range`, or `segmented-checked-interval`. A row is discharged only when (a) its exact call remains unique and matches the class's required local source expression (`self.index` lookup, concrete `RdfDataset::term_count`, same resident vector enumeration, or bounded segment mapping), and (b) the class's producer-source fingerprint still matches. Fingerprint the complete small authority items **and their encapsulating type/constructor paths**: `LocalCapacity::required`, `Interner::intern_with_memory`, `Interner` fields, freeze/clone path for frozen consumers; `GlobalDictionary` fields and `insert_missing`/`value_index`; `SegmentedBuildLimits::with_first_term_index`, builder admission, `seal` and pack migration. Where a complete constructor census is cumbersome, fingerprint the owning module rather than pretending a local expression proves the whole chain. A missing/duplicate/moved site, changed producer fingerprint, newly added term-table mutator, or added call site must fail the gate until reviewed. Regenerating fingerprints must require a source-backed review, not an automatic suppression command. Keep the manifest limited to the legitimate resident/interval rows in `logical-capacity-candidate-dispositions.md`; the public fixture/XPath input-dependent failures remain rule hits to fix with typed propagation.

This is an audited cross-method proof, not a static theorem prover. It is enforceable because it fails closed when either the exact consumer or its authority changes. A broad exemption based on `expect("stored term index is representable")` would accept a new unbounded mint under the same text and is specifically unsound. No checker/source edits or tests were performed for this design review.
