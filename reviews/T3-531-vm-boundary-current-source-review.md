# #531 current VM site and node-boundary review — 2026-10-13

**Scoped source PASS for the revised VM-site primitive and recursive `NodeBoundary` extraction.** The earlier two VM `REVISE` findings are resolved in the current uncommitted source. This does not qualify an iterative runner or the optimized depth floors.

`Linked<'e>` again retains a Rust borrow of the immutable expression root, now inside one admitted `SharedWorkspace<ExistsSites<'e>>`. `Suspend::Exists(u32)` carries only the compiled site ordinal; `resolve` requires the same borrowed root and walks an owner-relative path to the original `Expression::Exists`, so a distinct expression cannot silently replace the compiled owner. `Linked::fresh()` shallow-clones that shared owner; it no longer deep-clones unadmitted site paths in fork workers. The linker's DFS uses the existing `compile::visit_operands` ordering and admits the pending frames, active child list, path, per-site path and final site storage before growth. `ExistsSite` and `ExistsSites` declare payloads before their grants. When `program.has_exists()` is false, the path walk and shared site owner are absent. The `link_without_exists_admitted` missing-site failure remains. The checkpoint reports final-source evaluator strict compilation, VM 14/14, EXISTS 87, LATERAL 19 and runner-unwind 1/1, though this review ran none of them.

Against published `330c55f8c`, `NodeBoundary::enter` preserves raw bounded-admission then stack check, local Slice cap, source read check, and search-frame push. `start` preserves the no-governor fast path, pre-operator stop, node-cursor entry and entry charge; charge refusal leaves the cursor before constructing the truncated empty result. `finish` re-enters the node on success, commits output, then polls the post-operator stop and leaves the cursor. It leaves on error without output charge, then pops the search frame, clears local cap, checks the source read error, and only then combines successful outcome evidence and parent evidence. The new early cleanup of a locally installed cap after a read error or failed search push removes leaked temporary state without changing the returned error. The extraction adds a small stack state and calls the existing `evaluate` closure once; it adds no dispatch body or default-row heap allocation.

**Limits:** The current recursive caller passes its existing `RowDelivery`/`RowConsumer` closure through once, so source-level consumer routing is preserved. No worklist yet resumes a suspended child; no frame-owned copied-tree/VM handle for that path has been qualified. `NodeBoundary` has no runner-owned unwind cleanup for a panic during `evaluate`, and the current recursive source did not have that movable-state guarantee either. Its future use in an iterative loop must restore node cursors, search frames, local caps and scope tokens on all exits before copied AST owners drop. Focused first-error, evidence, Slice-cap, bounded admission, fork and async-consumer executions on this exact boundary source, the original optimized floors, allocation controls and full gates remain open.
