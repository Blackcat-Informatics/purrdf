# Tar synchronization history

The `sync/` tree is an unchanged copy of
`.stage/gts-expose-strict-lossless-tar/sync/`. A recursive comparison confirmed
identical file contents. It includes the complete recorded synchronization
attempt, events, accepted snapshot index and candidate patch.

This archive selects synchronization history only. Full qualification records
and raw review transcripts remain unchanged in the original local evidence
directory. Publication of the broader optional archive was refused by the
attribution guard. Restricted transcript bytes are not included here.

The journal's `validation_records` paths refer to the original evidence directory;
those records are not part of this archive and the journal does not certify
their outcomes. The signed squash notes and public pull request state the actual
qualified scope and final hosted results.
