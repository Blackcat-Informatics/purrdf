The assembler and postimages are Stage-only conveniences. Do not run the assembler after source integration: it deliberately checks exact old anchors and is not a shipping tool.

## Concrete owner and physical law

`NativeAdmission` owns the actual erased `WorkspaceCapability`, original `WorkspaceAllocation`, exact native live-byte total and first physical refusal. Its callback uses the shipping charge/resize methods; neutral `Memory` continues to perform every concrete fallible buffer growth. It is not a guessed per-term or source-length bound. Original typed source/admission errors remain latched in the execution account; the native error publisher returns the original evaluator marker before considering lexical failure.

A compiled program is `Shared<NativeProgram { pattern, storage }>` with the program declared before its original admission. `ProgramPublication` enlarges that same grant by `Shared::<NativeProgram>::allocation_layout()` before invoking the allocation-first Shared factory. The factory runs only after its destination exists; refusal leaves the original program and account enclosed. Shared clones copy neither program nor grant. The final-owner Shared destructor moves its unpinned payload onto the stack, frees the exact Header layout, then drops the payload. This keeps control storage covered through deallocation, even when payload destruction releases admission or unwinds. Existing checked count and multithread laws remain in place.

`Program::is_match(text, &capability)` calls the existing native `is_match_with_storage`; the copied Boolean escapes after native machine storage is destroyed. `Program::replace_literal` calls the existing native replacement with separate matcher/output admission. `StringLiteralPublication` settles the original output grant to its actual owned String capacity plus the datatype and language capacities. It admits and constructs all facets first. An owned Cow's original String moves without a second lexical allocation; a borrowed Cow receives a separately admitted fallible lexical copy. Only the final infallible `WorkspaceTerm::new` removes the original value/grant. The expression caller interns that retained term directly; the VM REGEX caller passes its real growth capability.

Native grammar/replacement failures remain SPARQL expression errors. Physical overflow, allocator refusal, native resource refusal and formatting failure remain hard operational errors; syntax diagnostic Strings never escape without their native owner. No request failure is inserted into the native cache. Successful linked/cache hits retain the original program and re-admit its stored source/program capacities under each request's current selected limits.

## Shared cache metadata

The existing private `BoundedCache` becomes one admitted `HashTable` home through `AdmittedMap`. Each entry stores previous/next key identities; head/tail keys live inline in the cache. Actual current K homes are `u64`, `(u64,u64)` and `Arc<[u8]>`; all clone without allocating. The existing table certificate prices the real `(K, Entry<K,V>)` layout including those links. New generic borrowed-key accessors call the same fixed-hash table body, preserving prepared-plan `[u8]` probes without key copies.

Ordinary touch/eviction uses a bounded number of hash lookups and allocation-free key clones. Only `u64` timestamp rollover walks the existing LRU links, with no temporary collection. Zero/oversize retention still permits execution; stats saturate only as observational counters. Physical allocation sizes and program fees are checked, not saturated. Resident callers use the same cache body with a resident capability; native callers use `insert_admitted` and propagate refusal. An insertion refusal can occur after retention evictions; the cache remains internally valid and the query hard-fails rather than publishing a hidden partial result.
