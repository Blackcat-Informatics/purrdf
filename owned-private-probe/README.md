## Whole workload contract

A completed receipt requires exactly 31 bundles, 5,580 original type-3 line features, 6,424 parts and 1,691,348 original vertices. There is no row/sample limit or prefix mode.

Every original ordinate is decoded from its binary64 bits through the one exact rational bridge. Every original feature passes complete WKT writer/reader equality and prepared identity, length/perimeter parity, cell assignment/hierarchy, closed-box membership and point index population. Every original vertex runs explicit CGCS2000 GK3, GK6 and UTM, inverse/forward residual and swapped-axis parity. Every original source edge runs continuous materialization for each of those three families. The caller's nearest-zone rule is explicit in this host and never added to the library. Its exact source parameter interval `[0,1]` is partitioned at every crossed zone wall and equator. Every closed piece is materialized under its explicitly declared zone and hemisphere, with original coordinate-linear interpolation, shared exact cut endpoints and a certificate of at most 0.1 metre. Different projected reference identities remain separate; pieces are never joined into a single projected line. `continuous_edges` counts a family/edge only after every piece succeeds; `continuous_pieces` reports the corresponding chart population. The original long written route is preserved without wrapping. A piece outside its admitted native domain, including the UTM latitude range, still fails visibly. No original interval is clipped, skipped or replaced by endpoint-only projection.

Counts in the final receipt must prove all three vertex and edge populations, every box membership, every indexed vertex and every feature identity/metric. Missing-datum-operation, missing-height, exact out-of-range and insufficient-work neighbors must refuse through the real native path. No fabricated WGS84 datum parameters, epoch, height, private polygon interior, GCJ assumption or private provider oracle is introduced.

Output is local aggregate evidence only: digests, populations, proof/error maxima, exact round-trip residual maxima, work/workspace maxima, refusals, completion coverage and elapsed time. Native errors remain owned inside the driver; presentation emits only static phase/class. A static panic hook is installed before acquiring any original input, so an unexpected native panic cannot format private numerical payloads. Neither failure Display/Debug nor source names, coordinates, DBF values or WKT are printed. An unexpected failure exits nonzero and cannot produce `status=complete`. Keep the complete local receipt outside selected Stage in the owned qualification directory with mode600; only aggregate populations, maxima and refusal classes may enter public Stage validation.
